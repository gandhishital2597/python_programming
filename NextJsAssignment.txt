Question 4.
Compare the folder structure of your Next.js project (insta-feed) with a basic Create React App project. List 3 differences you notice in how routing and pages are handled.
 Answer :
 Difference Between Next.js and Create React App

 1. Routing
Next.js: Has built-in routing using the folder and file structure.
CRA: Does not have built-in routing. We usually use React Router.

2. Pages
Next.js: Each route can have its own page.js file.
CRA: Usually uses components such as App.js, and React Router is used to display different pages.

3. Rendering
Next.js: Supports SSR (Server-Side Rendering), SSG, and CSR.
CRA: Mainly uses CSR (Client-Side Rendering) by default.

Question 5.
Write a short explanation (3-4 lines) on how SSR in Next.js can improve SEO for a food delivery app like Zomato, compared to using only client-side rendering (CSR).<br><br><em><strong>Hint:</strong> Think about how search engines see content and what loads first for users.</em>

Answer :
SSR in Next.js and SEO
SSR renders the food delivery page on the server and sends HTML content to the browser.
Search engines can easily read restaurant names, menus, locations, and other content from the initial HTML.
This can improve SEO and help pages appear more effectively in search results.
With only CSR, content is mainly loaded in the browser using JavaScript, which can delay the initial content display and make indexing more challenging.
